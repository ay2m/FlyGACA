Accessibility Statement for Fly GACA

Last updated: September 2026

Conformance Status

Fly GACA is committed to ensuring digital accessibility for aviation professionals, students, and enthusiasts. We are continually improving the user experience for everyone and applying the relevant accessibility standards.

The Web Content Accessibility Guidelines (WCAG) defines requirements for designers and developers to improve accessibility for people with disabilities. It defines three levels of conformance: Level A, Level AA, and Level AAA. Fly GACA is substantially conformant with WCAG 2.1 Level AA.

Accessibility Features

  • Color & Contrast: Strict adherence to 4.5:1 minimum contrast for normal text and 3:1 for graphical interface components.
  • Keyboard Navigation: All critical workflows (regulations search, flight calculators, study modules) are fully operable via keyboard.
  • Reduced Motion: Full support for prefers-reduced-motion system preferences across all kinetic animations.
  • Screen Reader Optimization: Proper ARIA landmark roles, semantic headings, and descriptive alternative text.

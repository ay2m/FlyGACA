**The 2026 target:** AI answers (Google AI Overviews/AI Mode, ChatGPT, Perplexity, Gemini) absorb a
large share of clicks; visibility = being the *cited source*. In priority order: crawlable HTML
(most AI bots don't run JS), answer-first structure, verifiable dated facts with named sources,
freshness, E-E-A-T + brand footprint, then schema. Fly GACA's cite-the-exact-Part/section ethos is
what these systems reward — lean into it.

**Target market:** Saudi Arabia, bilingual. English at clean paths, Arabic at `/ar/…` (real
documents, not `?lang=` variants). hreflang cluster is `en` · `ar` · `ar-SA` · `x-default`.

Status legend: `[x]` done · `[~]` partial (gap named) · `[ ]` not started.
Effort: S <½ day · M ~1 day · L multi-day.

## Where the pipeline stands (2026-08-19)

`npm run build` → sitemap+robots → `tsc -b` → vite → **head floor** (`prerender-head.mjs`) →
`check:prerender` → `check:jsonld`.
`npm run build:deploy` → all of the above → **full-body prerender** (`prerender.mjs`, Playwright) →
`check:prerender:coverage` → `check:jsonld` → `indexnow`. **Deploys must use `build:deploy`** —
plain `build` ships head-only HTML, which is invisible below the `<head>` to the crawlers that
decide citations.

Current output: **542 EN + 175 AR head snapshots; 715/715 sitemap URLs body-prerendered.**

## Deliberately not doing

- **llms.txt tooling.** Keep `public/llms.txt` accurate (it is, and now covers `/ar`), invest
  nothing more — measurement shows AI bots almost never fetch it.
- **Sitelinks search box as a Google feature.** Google **removed** it from results in November 2024;
  no markup brings it back there. We keep `WebSite`/`SearchAction` because other engines may use it
  and it tells any crawler that site search exists — now gate-enforced so it can't silently vanish.
  Ordinary Google **sitelinks** are earned structurally (breadcrumbs, hub ItemLists, clean titles),
  which the floor rollout above serves.
- **Mass content generation.** Demoted by the 2025–26 core updates.
- **RSS/Atom for `/updates`.** 0/306 corpus docs and all 6 sources carry real per-item dates today,
  so a feed would be a list of undated items. Revisit when the sync pipeline stamps effective dates.
- **Per-route OG image generation.** Five section cards + the default are enough; per-route cards add
  build weight for negligible citation value.
